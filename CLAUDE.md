## REGRA ABSOLUTA — PESQUISA ANTES DE CRIAR

NUNCA escreva uma única linha de conteúdo de curso, ebook ou qualquer material educativo sem ANTES executar uma pesquisa profunda e atualizada sobre:
1. O cenário atual do mercado/nicho do produto (dados de 2026, NUNCA use dados antigos)
2. Ferramentas, plataformas e tecnologias ATUAIS envolvidas no tema
3. Concorrência e produtos similares existentes
4. Público-alvo e suas dores REAIS e ATUAIS
5. Tendências e mudanças recentes do setor
6. Preços praticados pelo mercado atualmente

A pesquisa deve ser salva em curso/pesquisa-mercado.md com fontes confiáveis ANTES de qualquer criação de conteúdo. Esta regra se aplica a QUALQUER nicho, QUALQUER tema, QUALQUER produto. Sem pesquisa = sem conteúdo. ZERO tolerância para informações desatualizadas.

Data atual: estamos em 2026. NUNCA referencie dados como se fossem de 2024 ou 2025 sem contextualizar que são históricos.

# Fábrica de Infoprodutos com IA
## Projeto
Curso digital: "Fábrica de Infoprodutos com IA — Crie, Lance e Venda Produtos Digitais 100% com Claude"
Formato: App Web (produto principal) + Ebook PDF resumido (bônus)
Plataforma de venda: Kiwify
Hospedagem app web e página de vendas: Vercel (GitHub auto-deploy)
Público-alvo: Empreendedores digitais iniciantes e intermediários
Tráfego: Meta Ads (Facebook + Instagram)

## Regras Gerais
- Todo conteúdo em português brasileiro
- Tom: direto, prático, motivador, sem enrolação
- Copy AGRESSIVA: gatilhos mentais pesados, urgência, escassez, prova social, ancoragem de preço
- HTML responsivo, mobile-first, sem dependências externas
- Sempre gerar arquivos completos e prontos para uso
- App web: Next.js para deploy na Vercel
- Ebook: formato markdown bonito pronto para exportar PDF
