# 5 Prompts de Imagem — Criativos Meta Ads
**Fábrica de Infoprodutos com IA**

Cole estes prompts no ChatGPT (DALL-E), Midjourney, Leonardo AI ou qualquer gerador de imagem.
Gere cada um em **2 tamanhos**: 1080×1080 (feed) e 1080×1920 (stories/reels).

Paleta da marca: fundo preto (#07090f), verde neon (#00e87a), texto branco (#f8f8f8).

## DICAS DE USO

### ChatGPT / DALL-E
- Cole o prompt direto, funciona sem modificação
- Peça "generate in exactly 1080x1080 pixels" para o tamanho certo
- Se o texto ficou ilegível, peça: "Make all text larger and more readable"

### Midjourney
- Adicione no final: `--ar 1:1` (feed) ou `--ar 9:16` (stories)
- Adicione: `--style raw --v 7` para visual mais limpo
- Para mais contraste: `--s 250`

### Leonardo AI
- Use o modelo "DreamShaper" ou "Absolute Reality" para visual mais profissional
- Ative "Prompt Magic v3"
- Coloque resolução 1024×1024 e depois faça upscale

### Canva (via IA do Canva)
- Use os prompts como base e adapte no editor visual
- Advantage: pode editar textos exatos em português depois de gerar
